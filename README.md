# MORQEVA — Cloud Dark Vault Content OS

MORQEVA turns one story seed/title into a production-ready Dark Vault blueprint:

- live researched facts + source boundaries (Verified/Folklore modes)
- 5 ranked hooks
- exactly 10 scenes
- normalized 62-second master timing
- English main captions + smaller Darija in Latin/French letters
- detailed Flow / Nano Banana image prompts
- Meta Vibes motion prompts
- TikTok Symphony fallback prompts
- SFX + music cues
- production tracker → QC → distribution → analytics

The deployed app is designed for Streamlit Community Cloud + Supabase PostgreSQL + Gemini API.

See `DEPLOY.md` for the exact cloud setup.
